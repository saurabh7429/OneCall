Connection system update
- Main device now starts a local TCP server and UDP discovery listener when MainSetupFragment opens.
- Secondary device can enter the 6-digit code, discover the main device on the same Wi-Fi, and connect over TCP.
- Connected devices are surfaced live on the main setup screen.
- Auto-reconnect is persisted with the latest successful secondary connection record.

SIP server update
- Foreground SIP service added for main device; it starts on app launch when role is MAIN.
- Local SIP server (MjSip) listens on port 5060 and tracks registered secondary contacts.
- Secondary device registers as SIP client using sip:device_uuid@localip.
- Incoming phone call detection logs: INCOMING CALL DETECTED: [number].
- SIP INVITE broadcast to all registered secondary contacts; accept/decline paths cancel remaining calls.
